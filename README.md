# ParanáChuva — índices extremos de precipitação

Versão publicada (site estático) do dashboard dos índices extremos de chuva do boletim PARANÁ CHUVA (UFPR).

- Precipitação: CPC Global Unified Gauge-Based Daily Precipitation (NOAA PSL), 0,5°, 1979–2026.
- SPI: NOAA NCEI/NIDIS sobre o GPCC 1,0°.
- Malhas: IBGE.

Este repositório contém só o site compilado; o código-fonte fica no repositório do projeto.
